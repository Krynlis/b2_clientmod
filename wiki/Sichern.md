# Sichern

Du kannst Kisten, Fässer, Öfen, Werkstationen, Türen, Redstone-Teile und Truhen-/Trichterloren vor anderen Spielern schützen. Jeder Befehl wird mit einem **Rechtsklick** auf den Block oder das Fahrzeug abgeschlossen.

| Befehl | Wirkung |
|---|---|
| `/sichern` | Block sichern |
| `/entsichern` | Sicherung aufheben |
| `/info` | Eigentümer und Berechtigte anzeigen |
| `/vertrau <Spieler>` | Spieler für diesen einen Block freigeben |
| `/misstraue <Spieler>` | Freigabe für diesen Block entziehen |
| `/vertraualles <Spieler>` | Spieler für alle deine Blöcke freigeben (auch künftige) |
| `/misstraualles <Spieler>` | Freigabe für alle deine Blöcke entziehen |
