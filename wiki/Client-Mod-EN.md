# Client mod

You can only join Yvelgard with the client mod **yvelgard_clientmod**.

## Installation
1. Download the right file from the [releases](https://github.com/Krynlis/yvelgard_clientmod/releases):
   - Fabric or Quilt: `yvelgard_clientmod-fabric-…jar`, plus **Fabric API**
   - NeoForge: `yvelgard_clientmod-neoforge-…jar`
   - Forge: `yvelgard_clientmod-forge-…jar`
2. Put the file into your `mods` folder and start Minecraft 26.3.

## What the mod does for you
- **Language:** Your game language is sent to the server automatically. Items, menus and texts appear in your language. If you change the language in the options, everything updates right away.
- **Inventory:** key `E` opens the Yvelgard inventory.
- **Action keys 1–3:** default `R`, `G`, `V`, changeable under *Options → Controls → Key Binds → Yvelgard*.
- **Look:** buttons and sliders in wood and brass style.

## Privacy
The mod collects no data. It only talks to Yvelgard and only sends your language, the mod version and your key presses for inventory and actions.
