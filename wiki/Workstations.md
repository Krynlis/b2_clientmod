# Workstations

Many stations open their own menu instead of the normal window. Hover over an empty slot to see what belongs there.

| Station | Notes |
|---|---|
| Crafting table | 3x3 grid. Shift-click in your inventory puts items into the grid, shift-click on the result crafts as often as possible. |
| Crafter | Shift-right-click an empty slot to lock or unlock it. |
| Furnace, blast furnace, smoker | Keep running while closed. Bars show fuel and progress. Experience is given when taking out. |
| Brewing stand | Bars for blaze powder and brewing progress. |
| Grindstone | Removes enchantments (curses stay) and repairs two equal items. |
| Smithing table | Netherite upgrade and armor trims. |
| Stonecutter | All results as a grid; click crafts one, shift-click the whole stack. |
| Cartography table | Zoom out (paper), copy (empty map), lock (glass pane). |
| Loom | Insert banner, dye and optional pattern, pick a pattern by clicking. |

Anvil, enchanting table and beacon stay normal windows.
