# Discord

1. Gib im Spiel `/link` ein. Du bekommst einen sechsstelligen Code (anklicken zum Kopieren).
2. Gib im Blame2-Discord `/link <Code>` ein.

Danach wird dein Discord-Spitzname auf deinen Minecraft-Namen gesetzt, und du bekommst automatisch die Rollen für dein Volk und deinen Rang. `/unlink` löst die Verknüpfung wieder. Je nach Einstellung dürfen nur verknüpfte Spieler auf den Server; dann steht dein Code direkt in der Meldung beim Verbinden.
