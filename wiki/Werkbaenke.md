# Werkbänke

Viele Stationen öffnen ein eigenes Menü statt des normalen Fensters. Fährst du über ein leeres Feld, steht dort, was hineingehört.

| Station | Hinweise |
|---|---|
| Werkbank | 3x3-Raster. Shift-Klick im Inventar legt Items ins Raster, Shift-Klick aufs Ergebnis stellt so oft wie möglich her. |
| Crafter | Shift-Rechtsklick auf ein leeres Feld sperrt oder entsperrt es. |
| Ofen, Hochofen, Räucherofen | Laufen auch bei geschlossenem Fenster weiter. Balken zeigen Brennstoff und Fortschritt. Erfahrung gibt es beim Entnehmen. |
| Braustand | Balken für Lohenstaub und Brau-Fortschritt. |
| Schleifstein | Entfernt Verzauberungen (Flüche bleiben) und repariert zwei gleiche Gegenstände. |
| Schmiedetisch | Netherit-Aufwertung und Rüstungsverzierungen. |
| Steinsäge | Alle Ergebnisse als Raster; Klick stellt eins her, Shift-Klick den ganzen Stapel. |
| Kartentisch | Verkleinern (Papier), kopieren (leere Karte), sperren (Glasscheibe). |
| Webstuhl | Banner, Farbe und optional Mustervorlage einlegen, Muster per Klick wählen. |

Amboss, Zaubertisch und Leuchtfeuer bleiben normale Fenster.
