# Locking

You can protect chests, barrels, furnaces, workstations, doors, redstone parts and chest/hopper minecarts from other players. Each command is finished with a **right-click** on the block or vehicle.

| Command | Effect |
|---|---|
| `/sichern` | Lock a block |
| `/entsichern` | Remove the lock |
| `/info` | Show owner and trusted players |
| `/vertrau <player>` | Trust a player for this one block |
| `/misstraue <player>` | Remove trust for this block |
| `/vertraualles <player>` | Trust a player for all your blocks (including future ones) |
| `/misstraualles <player>` | Remove trust for all your blocks |
