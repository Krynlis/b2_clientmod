# Fishing

Instead of cod and salmon you catch **24 custom fish** in four weight classes: small, medium, large and huge. Many fish only bite in certain biomes, some only at night or by day, some only with the right bait. `/fische` shows what bites where you stand.

**Reeling minigame:** When a fish bites, reel in as usual. A menu opens. The first click starts the fight, then the fish swims back and forth. Click while it is in the green zone; missing costs line. With enough hits it is caught. If the line snaps, time runs out or you close the menu, it escapes. Heavier fish need more hits and move faster.

**Bait:** Shift-right-click with the rod opens the bait slot. The bait then sits in the rod (see its lore). Bait makes fish bite faster, attracts certain species, brings heavier fish, makes reeling easier or brings treasure more often. Bait is only used up when a fish bites; lures last several catches. Bait is made by the Humans in the bait box.

The **Angeln** skill rises with every catch, see [Skills](Skills-EN).

## Bait

| Bait | Effect |
|---|---|
| Earthworm | Attracts roach, perch, tench and eel. Faster bites. |
| Maggot | Very fast bites, but rather small fish. |
| Dough Ball | Carp and tench love it. |
| Sweetcorn | For carp and roach. |
| Baitfish | Attracts predators: pike, zander, catfish. Somewhat heavier catches. |
| Spinner | Lure for pike, perch, trout and zander. Lasts 20 catches. |
| Dry Fly | Daytime only. For trout and char. Lasts 5 catches. |
| Crab Meat | Attracts cod, halibut and ray. |
| Squid Strip | For deep sea fish and tuna. Somewhat heavier catches. |
| Glow Lure | The only bait for the anglerfish. Lasts 10 catches. |
| Ember Worm | The only bait for the emberfin. |
| Crystal Shard Lure | The only bait for the crystal trout. Lasts 5 catches. |
| Moondew | Night only. The only bait for the moonscale. |
| Shadow Moth | Night only. The only bait for the shadow pike. |
| Blossom Dough | Daytime only. The only bait for the cherry koi. |
| Spore Bread | Attracts the sporefish. Faster bites. |
| Frost Larva | The only bait for the frostfin, also attracts char. |
| Golden Lure | Large fish much more often, but slower bites. |
| Glitter Lure | More treasure instead of fish. Lasts 3 catches. |
| Honey Worm | Easier reeling: wider field, more line, slower fish. |
