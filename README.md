# yvelgard_clientmod

**Version:** 1.2.0.0
**Autor / Author:** Krynlis aka Street

---

## Deutsch

Fügt Eventhandler hinzu, die für das Spielen auf dem **Yvelgard-Server** benötigt werden. Die Mod sammelt keinerlei Daten.

📖 Alles zum Spielen auf Yvelgard steht im **[Wiki](https://github.com/Krynlis/yvelgard_clientmod/wiki)**.

### Eventhandler
- **Verbindung:** meldet dem Server, dass die Mod installiert ist
- **Inventar öffnen:** Taste `E`
- **Aktionstasten 1–3:** Standard `R`, `G`, `V`, änderbar unter *Optionen → Steuerung → Tastenbelegung → Yvelgard*

### Aussehen
- Alle Knöpfe und Schieberegler im Spiel im Holz- und Messing-Stil von Yvelgard

Auf anderen Servern und im Einzelspieler sendet die Mod nichts und alles bleibt wie gewohnt.

### Voraussetzungen
Minecraft Java Edition 26.3 und Java 25 oder neuer, dazu einer dieser Loader:

| Loader | Datei | Zusätzlich |
|---|---|---|
| Fabric | `yvelgard_clientmod-fabric-…jar` | Fabric API |
| Quilt | `yvelgard_clientmod-fabric-…jar` | Fabric API |
| NeoForge | `yvelgard_clientmod-neoforge-…jar` | – |
| Forge | `yvelgard_clientmod-forge-…jar` | – |

### Installation
1. Den passenden Loader für Minecraft 26.3 installieren.
2. Die passende Datei aus den Releases (bei Fabric und Quilt zusätzlich Fabric API) in den Ordner `mods` legen.
3. Minecraft mit dem Loader-Profil starten.

## English

Adds event handlers required for playing on the **Yvelgard server**. The mod collects no data at all.

### Event handlers

📖 Everything about playing on Yvelgard is in the **[wiki](https://github.com/Krynlis/yvelgard_clientmod/wiki)**.
- **Connection:** tells the server that the mod is installed
- **Open inventory:** key `E`
- **Action keys 1–3:** default `R`, `G`, `V`, changeable under *Options → Controls → Key Binds → Yvelgard*

### Look
- All buttons and sliders in the game in Yvelgard's wood and brass style

On other servers and in singleplayer the mod sends nothing and everything stays as usual.

### Requirements
Minecraft Java Edition 26.3 and Java 25 or newer, plus one of these loaders:

| Loader | File | Also needed |
|---|---|---|
| Fabric | `yvelgard_clientmod-fabric-…jar` | Fabric API |
| Quilt | `yvelgard_clientmod-fabric-…jar` | Fabric API |
| NeoForge | `yvelgard_clientmod-neoforge-…jar` | – |
| Forge | `yvelgard_clientmod-forge-…jar` | – |

### Installation
1. Install the matching loader for Minecraft 26.3.
2. Put the matching file from the releases (plus Fabric API for Fabric and Quilt) into the `mods` folder.
3. Start Minecraft with the loader profile.
